# Лаб 01 - B232270068 А.Баяржавхлан

## Хийсэн ажлын хураангуй
Playwright сан ашиглаж SauceDemo вебсайтад зориулсан UI тестүүд бичсэн. Амжилттай, амжилтгүй нэвтрэлт болон сагсанд бараа нэмэх үйлдлүүдийг автоматаар тестлэсэн. Codegen ашиглан тест үүсгэж, бичсэн тестээс ямар ялгаатайг нь тодорхойлсон.

Тестүүд ажиллаж байгааг харуулсан бичлэгийг `playwright.config.ts`-д `'video': on` гэж тохируулан хийсэн. `docs/playwright-report/` хавтаст Playwright тайланг хавсаргасан.


## XPath
XPath нь HTML DOM-ын бүтцээс хамааралтай учир бага зэргийн өөрчлөлт тестийг эвдэх магадлалтай. Мөн XPath ашигласан тест нь эх кодыг харахгүйгээр ойлгоход хэцүү.


## Codegen
- Codegen ашиглан үүсгэсэн код нь хэрэглэгчийн хийж үйлдлүүдийг бичиж авах хэлбэрээр үүсдэг. Бичсэн тест нь placeholder текстээр нь хайх зэргээр хүн ойлгохоор, хүмүүсийн байна. Харин Codegen нь CSS, HTML attribute ашиглан элементийг сонгож байна. Мөн хэрэглэгчийн хийсэн илүүц, тест хийх шаардлагагүй үйлдлүүдийг бүгдийг нь бичиж авч байна.
- Codegen-ий үүсгэсэн тестийг өөрчлөх, ойлгоход төвөгтэй, мөн UI кодод өөрчлөлт ороход амархан эвдэрэх магадлалтай.


## Trace
Trace ашиглаж тест яаж ажиллаж байгааг харсан. Мөн нэг тестээ зориудаар унагаж, ямар алдаа гарсныг харсан.

## Playwright vs Selenium
Playwright, Selenium хоёул нээлтэй эхийн программ, гэхдээ хэдэн ялгаатай. Лабораторийн удирдамжид дурдсанчлан Playwright нь илүү орчин үеийн, хөнгөн, ашиглахад хялбар байхаар бүтээгдсэн. Хамгийн гол ялгаа нь Playwright-д хүлээлт (wait) гараар бичих шаардлагагүй. Selenium нь илүү олон программчлалын хэл дэмждэг ч орчин үеийн веб технологид энэ нь том давуу тал болж чадахгүй. Selenium-ийг хэрэглэхэд browser бүрт зориулсан driver суулгах шаардлагатай байдаг бол Playwright нь суулгах явцдаа integrated browser давхар суулгаж, хэрэглэгчийн цагийг хэмнэж байна. Playwright-н өөр нэг давуу тал нь trace хийх. Selenium нь log болон screenshot-д тулгуурлан debug хийх боломж олгодог нь Playwright-н trace-тэй харьцуулахад хоцрогдсон байна.
