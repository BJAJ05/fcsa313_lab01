## Codegen
- Codegen ашиглан үүсгэсэн код нь хэрэглэгчийн хийж үйлдлүүдийг бичиж авах хэлбэрээр үүсдэг. Бичсэн тест нь placeholder текстээр нь хайх зэргээр хүнд ойлгогдох, семантиктай байна. Харин Codegen нь CSS, HTML attribute ашиглан элементийг сонгож байна. Мөн хэрэглэгчийн хийсэн илүүц, тест хийх шаардлагагүй үйлдлүүдийг бүгдийг нь бичиж авч байна.
- Codegen-ий үүсгэсэн тестийг өөрчлөх, ойлгоход төвөгтэй, мөн UI кодод өөрчлөлт ороход амархан эвдэрэх магадлалтай.
